# 빛마루 (Bitmaru)

땅 아래에서 빛과 식물이 자라는 정원 도시를 콘셉트로 만든 정적 웹사이트예요. 빌드 과정 없이 HTML 파일 그대로 GitHub Pages에 올리면 돼요.

| 페이지 | 하는 일 | 데이터베이스 필요 여부 |
|---|---|---|
| `index.html` | 빛의 정원: 누르면 꽃이 피고, 끌면 바람이 불고, 시간대·소리를 바꾸고, 링크로 정원 공유 | 새 글 목록만 필요 |
| `viewer.html` | 폰 스캔 3D 파일(GLB, OBJ, PLY, STL, FBX, USDZ 일부) 보기, 평면도, 걸어보기, 측정, 천장 자르기, 벽에 사진 걸기 | 필요 없음 |
| `map.html` | OpenStreetMap 지도 위에 집·공원·건물 3D 모델을 실제 위치에 놓고, 눌러서 3D로 보기 | 필요 없음 |
| `board.html` | 누구나 쓰는 게시판 (글, 댓글) | 필요 |
| `refs.html` | GitHub 추천 저장소를 방문할 때마다 무작위로 10개 보여줌 | 필요 없음 |
| `account.html` | 가입, 로그인, 관리자 설정 | 필요 |

## 1. GitHub Pages 켜기

1. 저장소의 **Settings → Pages**로 가요.
2. **Source**를 `Deploy from a branch`로, 브랜치는 `main`, 폴더는 `/ (root)`로 고르고 저장해요.
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/`에서 사이트가 열려요.

3D 뷰어와 참고자료는 이 단계만 해도 바로 써요.

## 2. Supabase 연결하기 (가입·게시판)

GitHub Pages는 파일만 보여주는 곳이라서 회원 정보와 글은 [Supabase](https://supabase.com)(무료 요금제 있음)에 저장해요.

1. supabase.com에서 가입하고 **New project**를 만들어요. 지역은 `Northeast Asia (Seoul)`을 추천해요.
2. 왼쪽 메뉴 **SQL Editor**를 열고, 이 저장소의 `supabase/schema.sql` 내용을 전부 붙여넣고 **Run**을 눌러요.
3. **Project Settings → API**에서 `Project URL`과 `anon public` 키를 복사해요.
4. `assets/js/config.js`에 붙여넣고 커밋해요.

   ```js
   window.UL_CONFIG = {
     supabaseUrl: 'https://xxxx.supabase.co',
     supabaseAnonKey: 'eyJ...',
   };
   ```

   anon 키는 공개용이라 저장소에 올려도 괜찮아요. **`service_role` 키는 절대 넣지 마세요.**
5. **Authentication → URL Configuration**의 `Site URL`에 GitHub Pages 주소를 넣어요. 가입 확인 메일의 링크가 이 주소로 돌아와요.

## 3. 첫 가입 = 관리자

- `account.html`에서 **가장 먼저 가입한 사람이 자동으로 관리자**가 돼요. 사이트를 열자마자 본인이 먼저 가입하세요.
- 관리자는 계정 페이지에서 사이트 이름, 첫 화면 공지, 게시판 열기·잠그기, 회원 등급을 바꿀 수 있어요.
- 회원 전용 모드를 끄면 게시판은 로그인하지 않아도 누구나 글과 댓글을 쓸 수 있어요. 비회원 글은 관리자만 지울 수 있어요.
- 이 규칙은 브라우저 코드가 아니라 데이터베이스의 행 수준 보안(RLS)이 지켜요. 그래서 누가 브라우저 코드를 고쳐도 남의 글을 지우거나 관리자가 될 수 없어요.

## 회원 전용으로 쓰기

- **회원 전용** (기본 켜짐): 로그인하지 않은 사람은 모든 페이지에서 계정 페이지로 보내지고, 게시판 글도 데이터베이스에서 보이지 않아요.
- **새 가입 받기**: 본인이 관리자로 가입한 뒤 이걸 끄면, 다른 사람은 아예 가입할 수 없어요. (데이터베이스가 거절해요.)
- 둘 다 계정 페이지의 관리자 설정에서 바꿔요.
- 주의: GitHub Pages의 HTML·JS 파일 자체는 주소를 아는 누구나 받을 수 있어요. 보호되는 건 데이터(글, 회원)예요. 지도와 3D 뷰어의 모델·사진은 처음부터 각자 브라우저에만 저장돼서 남이 볼 수 없어요.

## 지도 사용법

- 지도를 누르거나 주소로 찾거나 "내 위치"로 위치를 정하고, 3D 파일을 골라 **지도에 놓기**를 눌러요.
- 핀을 누르면 3D로 볼 수 있고, 핀을 끌어서 위치를 옮길 수 있어요.
- 모델은 그 브라우저의 저장소(IndexedDB)에 저장돼서 다른 기기에서는 보이지 않아요.
- 지도 데이터: © OpenStreetMap 기여자. 주소 검색: Nominatim.

## 참고자료 목록 고치기

`assets/js/refs-data.js`에 `{ repo: '소유자/저장소', cat: '분류', desc: '설명' }` 형식으로 추가하면 돼요.

## 3D 뷰어 팁

- 스캔 앱에서 **GLB**로 내보내는 게 가장 잘 열려요.
- OBJ는 `.obj`, `.mtl`, 질감 이미지를 한꺼번에 선택하세요.
- 아이폰 앱이 만든 USDZ와 Draco로 압축된 GLB는 열리지 않아요.
- 파일과 사진은 브라우저 안에서만 열리고 서버로 올라가지 않아요.
